# Описание программного проекта

## 1. Назначение системы

Система предназначена для оформления и контроля пропусков.

## 2. Пользователи системы

Основные категории пользователей:

- заявитель;
- сотрудник службы безопасности;
- администратор.

## 3. Основные функции

- регистрация и аутентификация пользователей;
- создание и просмотр заявок на оформление пропусков;
- изменение состояния заявок и пропусков;
- поиск и фильтрация данных;
- разграничение доступа;
- журналирование событий безопасности;
- формирование отчетов.

## 4. Обрабатываемые данные

Система может обрабатывать:

- идентификационные данные пользователей;
- учетные данные;
- сведения о заявках и пропусках;
- статусы и историю изменений;
- записи журнала событий.

## 5. Защищаемые активы

К основным защищаемым активам относятся:

- учетные записи пользователей;
- пароли и секретные ключи;
- прикладные данные;
- программный код;
- файлы конфигурации;
- журналы безопасности;
- база данных;
- сетевые соединения.

## 6. Программные и сетевые компоненты

Первоначальная архитектура включает:

- пользовательский интерфейс;
- серверное приложение на Python;
- модуль конфигурации;
- модуль аутентификации;
- модуль управления доступом;
- базу данных;
- подсистему журналирования;
- набор автоматических тестов;
- сетевое соединение между пользовательским интерфейсом и серверным приложением.
